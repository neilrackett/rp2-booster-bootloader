Available Apps

This page lists the micro-firmwares you can install, launch, or remove.

  • Release type: All lists everything. Stable hides beta versions, Beta shows only beta versions.
  • Platform, Features and Creator: click the chips to filter the list. Combine filters to narrow the catalog.
  • Action button (Install / Update / Downgrade): installs the version selected in the dropdown, latest by default. Downgrades ask for confirmation.
  • Launch: starts an installed app. To return here later, press the SELECT button on the device and follow the on-screen instructions.
  • Restore and launch (DEV APP only): starts the DEV APP from a clean slate. It replaces the microfirmware on the device with the version downloaded from the catalog, erases the DEV APP's saved settings and deletes the last upload.
  • Restore config only (DEV APP only): erases the DEV APP's saved settings, so it starts with its defaults the next time it runs. The microfirmware on the device and the last upload are kept, and nothing is launched.
